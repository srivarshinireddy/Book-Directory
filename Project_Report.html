1. Entity Relationship Design

For this project, the entities chosen are Author and Book. The application models a library system where an author can write multiple books, and each book belongs to exactly one author.

  • Author Entity: Contains id (Primary Key), name, nationality, and a @OneToMany relationship mapping to the Book entity.
  • Book Entity: Contains id (Primary Key), title, price, and a @ManyToOne relationship mapping to the Author entity.

The JPA annotations @Entity, @Id, @GeneratedValue, @OneToMany, and @ManyToOne were used to properly define these database constraints and relationships.

An in-memory H2 Database was configured using application.properties. Data is initialized using a data.sql script which is automatically executed by Spring Boot on startup, inserting 10 sample records for both authors and books.

2.2 Create Operation

A reusable JSP view (form.jsp) allows users to add new entities. The LibraryController handles the POST request, catching any DataIntegrityViolationException to gracefully handle integrity issues.

@PostMapping
public String saveBook(@ModelAttribute("book") Book book, Model model) {
    try {
        libraryService.saveBook(book);
        return "redirect:/books";
    } catch (DataIntegrityViolationException e) {
        model.addAttribute("error", "Data integrity violation: Ensure all fields are valid.");
        model.addAttribute("authors", libraryService.getAllAuthors());
        return "form";
    }
}

2.3 Read Operation

A JSP view (list.jsp) lists all entities. To satisfy the custom query requirement, a JOIN FETCH query was implemented in the repository to retrieve books and their authors in a single SQL inner join.

@Repository
public interface BookRepository extends JpaRepository<Book, Long> {
    @Query("SELECT b FROM Book b JOIN FETCH b.author")
    List<Book> findAllBooksWithAuthors();
}

2.4 Update Operation

The update operation utilizes the same form.jsp, pre-filling the existing entity's details. The controller saves the modified entity using JPA's save mechanism.

@PostMapping("/update/{id}")
public String updateBook(@PathVariable("id") Long id, @ModelAttribute("book") Book book) {
    book.setId(id);
    libraryService.saveBook(book);
    return "redirect:/books";
}

3. Challenges Faced and Solutions

  • Challenge: Handling Data Integrity Exceptions properly without causing the application to crash or display the default "Whitelabel Error Page".
    Solution: A try-catch block was added in the Controller methods for POST requests. If an exception is caught, an error attribute is passed to the Model, and the form is returned with a descriptive error message displayed to the user using JSTL.
  • Challenge: Configuring JSP in modern Spring Boot (version 3.2+). Spring Boot typically favors Thymeleaf.
    Solution: The tomcat-embed-jasper dependency and modern Jakarta JSTL dependencies were manually added to the pom.xml, and the view resolver was properly mapped via the application.properties file.
